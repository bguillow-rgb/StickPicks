# Framing Guide — How to Describe Stick Picks Without Promoting Tobacco

**This is the first doc to read** and the one to re-read whenever you
edit any external-facing copy. App Store Review Guideline 1.4.3 lets
apps that *reference* tobacco exist, but will reject apps that
*encourage consumption*. Every word we publish should fall on the
right side of that line.

## The official framing

Stick Picks is a **lifestyle and hobby app for cigar collectors**. It
catalogs a user's personal collection, organizes their humidor,
tracks the value of what they own, and provides a rich reference
database of cigar brands and vitolas.

We do not:
- sell cigars or any tobacco product
- facilitate tobacco purchases
- promote, encourage, or condone smoking
- make health claims (positive or negative) about tobacco use
- target minors — the app enforces a 21+ age gate on first launch

## Words to use

| Instead of… | Use… |
|---|---|
| "smoking cigars" | "collecting cigars" / "cataloging cigars" |
| "smoke a cigar" | "record a cigar in your journal" / "log a cigar" |
| "what cigars to try" | "cigars in your reference catalog" |
| "tobacco aficionado" | "cigar collector" / "cigar enthusiast" |
| "cigar lounge" | "humidor" / "collection" |
| "light up" | *never — no replacement needed* |
| "puff / draw / burn" | *never — no replacement needed* |
| "pairing" (as in smoking + drinking) | *avoid entirely in marketing copy* |
| "flavor notes from smoking" | "flavor profile / tasting notes" (neutral) |

## Concepts to emphasize

- **Collection journaling** — the app captures a collector's personal
  record of what they have. Akin to Vivino (wine), Distiller (whisky),
  CellarTracker (wine cellar).
- **Humidor organization** — the humidor is a piece of furniture and
  an inventory category; organizing it is a hobby activity, not a
  consumption activity.
- **Valuation** — collectibles have value. Tracking value is a
  collector's concern, not a smoker's concern.
- **Reference catalog** — looking up what a cigar is, its origin, its
  construction — this is reading about the hobby, not consuming it.
- **Photo identification** — recognizing a band to catalog a stick is
  inventory work.
- **21+ adult hobby** — state this plainly. It reinforces that we're
  serious about age restrictions.

## Concepts to avoid

- Health-framed language of any kind. Don't say "enjoy responsibly,"
  don't say "great for relaxation," don't deny any health claim.
  Neutral silence.
- Purchase / acquisition recommendations that read like product
  promotion. "Discover your next favorite" — no. "Catalog your
  favorites" — yes.
- The word "smoke" in any tense in any marketing copy. (The in-app
  humidor has a "smoked" status label — that's a technical user
  state, not marketing. It stays inside the UI, never in the App
  Store listing.)
- Language that glorifies tobacco use. Luxury lifestyle imagery is
  fine (humidor woodgrain, leather, etc.) — smoking imagery is not.

## The test

Read any sentence of copy aloud. Ask:

> Would this make sense if I replaced "cigar" with "vintage stamp"
> or "baseball card"?

If yes, the framing is about collection, not consumption. Ship it.
If the sentence only works because cigars are smoked, rewrite it.

## If a reviewer pushes back

Apple occasionally rejects cigar/tobacco-adjacent apps under 1.4.3
even when framed as collection tools. If that happens:

- Point out the 21+ age gate (enforced in code, not just UI copy).
- Point out we don't sell anything through the app.
- Point out the app's core feature is **inventory + journal**, not
  recommendations to consume.
- Cite precedent: Distiller, CellarTracker, and Vivino are all
  accepted apps for age-restricted beverage collection/journaling.

Never agree that the app promotes consumption. It doesn't, and
agreeing muddies the record for future reviews.
